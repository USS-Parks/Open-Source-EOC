Runtimes
--------

Node.js

  bundles: licenses/node-LICENSE.txt. npm and Corepack keep their own
  license files under runtime/node/node_modules.

PostgreSQL
  runtime/pgsql, the PostgreSQL Windows x64 binaries published by EDB,
  under the PostgreSQL License: licenses/postgresql-server_license.txt.

PostGIS and the PostGIS Windows bundle

  - PostGIS 3.6.2, which the PostGIS project licenses under the GNU General

    licenses/postgis-bundle-LICENSE-Apache-2.0.txt.
  - pgSphere: licenses/pg_sphere-COPYRIGHT.txt.
  - ogr_fdw, under the MIT License: licenses/ogr_fdw-LICENSE.md.

    licenses/gdal-LICENSE.txt.
  The bundle also contains GEOS, PROJ, SFCGAL, CGAL, Boost, GMP, MPFR, GSL,

  not include their license texts.

Caddy
  runtime/caddy/caddy.exe, the official Caddy 2.11.4 Windows x64 release,
  which serves the network host over HTTPS. Apache License 2.0:
  licenses/caddy-LICENSE.txt. Caddy is built from Go modules under their
  own licenses, mostly Apache 2.0, BSD and MIT; "caddy.exe build-info"
  lists each module and version.

WinSW
  runtime/winsw/WinSW-x64.exe, WinSW 2.12.0, which runs the network host's

  licenses/winsw-LICENSE.txt.

TypeScript
  node_modules/typescript, which runs the server's TypeScript sources.
  Apache License 2.0: node_modules/typescript/LICENSE.txt.

Server npm packages
  server/node_modules holds the server's production dependencies. Each
  package keeps its package.json, which declares its license, and nearly
  all keep their own license file beside it. When this file was written,
  three did not: postgres, under the Unlicense, a public-domain dedication;
  and abstract-logging and @nodable/entities, under the MIT License as
  their package.json and README state.

Web application
  web/dist is compiled from the web workspace's npm packages, under the
  licenses each package declares. The MapLibre GL JS worker file keeps its
  BSD-3-Clause license header. In the source repository,
  scripts/license-scan.mjs checks every installed package's declared
  license against the licenses the project refuses.


Map data
--------

OpenStreetMap (when included)
  These files are databases derived from OpenStreetMap:
  - web/public/basemap/california.pmtiles, the street basemap;
  - web/public/basemap/buildings.pmtiles, building footprints;
  - tools/basemap/out/gazetteer.tsv, the address search gazetteer.

  © OpenStreetMap contributors. The data is available under the Open
  Database License 1.0 (ODbL): https://opendatacommons.org/licenses/odbl/1-0/
  See also https://www.openstreetmap.org/copyright. The map shows this
  attribution while the street or building archive is in use.

  Each file above is a whole derived database, conveyed under the ODbL. It
  was made from the Geofabrik extract of California,
  https://download.geofabrik.de/north-america/us/california.html, with the
  build tools in the Open Source EOC source repository:
  tools/basemap/generate-california.sh builds the street and building
  archives with Planetiler, tools/basemap/build-overture-buildings.ps1 adds
  the Overture values below to the building archive, and
  tools/basemap/build-gazetteer.mjs builds the gazetteer from the street
  archive. tools/basemap/README.md in that repository describes each step.

Overture Maps buildings (when included)
  web/public/basemap/buildings.pmtiles carries building use and subtype
  values from the Overture Maps Foundation buildings release named in
  web/public/basemap/buildings-overture.json, matched to OpenStreetMap
  ways. © Overture Maps Foundation. Open Database License 1.0, as above.

California road jurisdiction and public land overlays (when included)
  web/public/basemap/overlays.pmtiles is compiled from public agency map
  services: the Caltrans State Highway Network; USDA Forest Service roads;
  Bureau of Land Management public motorized roads; National Park Service
  public roads; CAL FIRE public land ownership, compiled from the
  California Protected Areas Database and US Fish and Wildlife Service,
  Department of Defense and Bureau of Indian Affairs data; and Humboldt
  County GIS roads. web/public/basemap/overlays-manifest.json records each
  source's address and attribution. The source services declare no reuse
  license, and the terms for redistributing this compilation are under
  review.

California critical facilities (when included)
  web/public/basemap/facilities.pmtiles is compiled from United States
  Government public domain data (the USGS National Structures Dataset, FEMA,
  CMS, Census TIGER/Line, EIA, EPA, FCC, FAA, USACE, FHWA and BTS) and from
  OpenStreetMap points in the street basemap. The OpenStreetMap part makes it
  a database derived from OpenStreetMap, conveyed under the Open Database
  License 1.0 with the attribution above.
  web/public/basemap/facilities-manifest.json records each source's address,
  license, retrieval date, size and SHA-256. tools/basemap/build-facilities.mjs
  builds it.

California tribal areas, counties and places (when included)
  web/public/basemap/boundaries.pmtiles is compiled from United States
  Government public domain data: U.S. Census Bureau TIGER/Line American
  Indian, Alaska Native and Native Hawaiian Areas and Cartographic Boundary
  Files, and the Bureau of Indian Affairs AIAN Land Area Representations.
  BIA states that its representations are for illustrative, reference and
  statistical purposes, that no legal inference can or should be made from
  them, and that they have no impact on the legal status of the land areas
  or on land ownership; web/public/basemap/boundaries-manifest.json records
  BIA's disclaimer in full with each source's address, license, retrieval
  date, size and SHA-256.

California risk and social vulnerability (when included)
  web/public/basemap/risk.pmtiles holds FEMA National Risk Index v1.20
  ratings and CDC/ATSDR Social Vulnerability Index 2022 rankings on U.S.
  Census Bureau tract and county boundaries. This product uses the Federal
  Emergency Management Agency's National Risk Index dataset API or
  downloadable datasets but is not endorsed by FEMA. The Federal Government
  or FEMA cannot vouch for the data or analyses derived from these data
  after the data have been retrieved from the Agency's website(s). The Risk
  Index is for planning purposes and is not a local risk assessment. SVI
  citation: Centers for Disease Control and Prevention/Agency for Toxic
  Substances and Disease Registry/Geospatial Research, Analysis, and
  Services Program. CDC/ATSDR Social Vulnerability Index 2022 Database U.S.
  web/public/basemap/risk-manifest.json records FEMA's terms, the retrieval
  date and time, and each source's address, size and SHA-256.
  tools/basemap/build-reference-layers.mjs builds both archives.

Bundled basemap
  web/public/basemap/basemap.pmtiles and ca_counties.geojson come from
  Natural Earth and US Census boundaries, both in the public domain.
